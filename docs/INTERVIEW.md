# Interview Notes

## 30초 소개

FOMO Guard는 사용자의 포트폴리오가 최근 시장 분위기와 단기 성과 추종의 영향을 받아 형성되었는지 점검하는 웹 대시보드입니다. CSV나 샘플 데이터를 입력하면 자산 비중, 최근 편입 여부, 최근 수익률, 섹터 쏠림을 분석해 FOMO 점수와 점검형 인사이트를 제공합니다.

## 1분 소개

일반적인 투자 화면은 평가금액과 수익률을 보여주지만, 사용자가 최근 급등한 자산을 뒤늦게 편입했는지, 성과가 좋았던 자산에 비중이 몰렸는지는 설명하지 못합니다. FOMO Guard는 매수일, 최근 수익률, 비중 변화율, 섹터 비중을 활용해 FOMO 위험을 규칙 기반으로 진단합니다. 외부 금융 API 대신 정적 웹앱과 샘플 CSV를 사용해 별도 설정 없이 데모가 가능하도록 만들었습니다.

## 예상 질문과 답변

### Q1. 왜 이 프로젝트를 만들었나요?

단순 수익률 화면은 사용자가 최근 시장 분위기에 영향을 받았는지 설명하지 못합니다. 그래서 포트폴리오의 형성 흐름을 점검하는 대시보드를 만들었습니다.

### Q2. 왜 외부 금융 API를 사용하지 않았나요?

제출 환경에서 API 키, 인증, 네트워크 문제가 생기면 데모가 실패할 수 있습니다. 그래서 정적 웹앱과 CSV 업로드 방식으로 재현성을 우선했습니다.

### Q3. FOMO 점수는 어떻게 계산하나요?

후행 편입, 성과 추종, 후행 섹터 집중, 단일 자산 집중, 섹터 편중을 종합해 점수를 계산합니다.

### Q4. 투자 추천 서비스와 어떻게 다른가요?

어떤 종목을 사거나 팔라고 말하지 않습니다. 결과는 모두 포트폴리오 상태 점검과 행동 가이드에 한정됩니다.

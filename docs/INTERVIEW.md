# Interview Notes

이 문서는 FOMO Guard를 발표하거나 면접에서 설명할 때 사용할 수 있는 답변 정리입니다.

## 30초 소개

FOMO Guard는 사용자의 포트폴리오가 최근 시장 분위기와 단기 성과 추종의 영향을 받아 형성되었는지 점검하는 웹 대시보드입니다. CSV나 샘플 데이터를 입력하면 자산 비중, 최근 편입 여부, 최근 수익률, 섹터 쏠림을 분석해 FOMO 점수와 점검형 인사이트를 제공합니다. 특정 종목을 추천하지 않고, 사용자가 스스로 투자 이유를 확인하도록 돕는 것이 핵심입니다.

## 1분 소개

FOMO Guard는 단순 수익률 대시보드가 아니라 포트폴리오의 형성 흐름을 해석하는 서비스입니다. 일반적인 투자 화면은 평가금액과 수익률을 보여주지만, 사용자가 최근 급등한 자산을 뒤늦게 편입했는지, 성과가 좋았던 자산에 비중이 몰렸는지는 설명하지 못합니다.

이 프로젝트는 CSV 기반으로 포트폴리오를 입력받고, 매수일, 최근 7일/30일 수익률, 비중 변화율, 섹터 비중을 활용해 FOMO 위험을 규칙 기반으로 진단합니다. 외부 금융 API 대신 정적 웹앱으로 구현해 해커톤 심사자가 별도 설정 없이 바로 실행할 수 있게 했습니다. 또한 매수/매도 권유 문구를 제거하고 점검형 가이드만 제공해 투자 추천 서비스로 오해되지 않도록 설계했습니다.

## 예상 질문과 답변

### Q1. 왜 이 프로젝트를 만들었나요?

단순히 투자 수익률을 보여주는 화면은 많지만, 사용자가 최근 시장 분위기에 끌려 포트폴리오를 구성했는지 점검해주는 도구는 부족하다고 생각했습니다. 그래서 "무엇을 살까"가 아니라 "왜 지금 사고 싶어졌을까"를 묻는 대시보드를 만들었습니다.

### Q2. 왜 외부 금융 API를 사용하지 않았나요?

해커톤 제출물에서는 심사자가 바로 실행할 수 있는 안정성이 중요했습니다. 외부 API를 쓰면 API 키, 인증, 네트워크 문제가 생길 수 있어서 샘플 CSV와 직접 업로드 방식으로 재현 가능한 MVP를 만들었습니다.

### Q3. FOMO 점수는 어떻게 계산하나요?

FOMO 점수는 단일 수익률이 아니라 여러 행동 신호를 합산합니다. 최근 급등 후 편입, 성과 추종, 후행 섹터 집중, 단일 자산 집중, 섹터 편중을 기준으로 점수를 부여하고 종합 위험도를 계산합니다.

### Q4. 투자 추천 서비스와 어떻게 다르나요?

FOMO Guard는 어떤 종목을 사거나 팔라고 말하지 않습니다. 모든 문장은 "가능성이 있습니다", "점검이 필요합니다", "확인해보는 것이 좋습니다"처럼 사용자가 스스로 판단 근거를 점검하도록 돕는 형태로 작성했습니다.

### Q5. 개발 중 가장 어려웠던 점은 무엇인가요?

FOMO를 단순 수익률로 판단할 수 없다는 점이 가장 어려웠습니다. 같은 비중이라도 장기 보유인지 최근 급등 후 편입인지에 따라 의미가 달라지기 때문에, 매수일과 최근 수익률, 비중 변화율을 함께 고려하는 시간 흐름 기반 진단으로 설계를 바꿨습니다.

### Q6. 이 프로젝트에서 본인이 강조하고 싶은 역량은 무엇인가요?

문제를 단순 기능으로 보지 않고 사용자 행동과 판단 흐름으로 재정의한 점입니다. 또한 규칙 문서, 입력 명세, 가드레일, README, Mermaid 다이어그램까지 정리해 구현 결과뿐 아니라 의사결정의 근거를 남긴 점을 강조하고 싶습니다.

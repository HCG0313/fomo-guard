# FOMO Guard Docs

이 폴더는 FOMO Guard를 취업 포트폴리오 관점에서 설명하기 위한 보조 문서입니다. 루트 `README.md`가 첫 화면 요약이라면, 이 폴더는 면접관이나 리뷰어가 더 깊게 확인할 수 있는 근거 자료입니다.

## 문서 목록

| 문서 | 목적 |
| --- | --- |
| `ARCHITECTURE.md` | 서비스 구조, 데이터 흐름, 모듈 역할, 기술 선택 이유 |
| `TROUBLESHOOTING.md` | 개발 중 겪은 문제와 해결 과정 |
| `RETROSPECTIVE.md` | 프로젝트 회고, 배운 점, 한계와 개선 방향 |
| `INTERVIEW.md` | 30초 소개, 1분 소개, 예상 면접 질문과 답변 |

## 읽는 순서

1. 루트 `README.md`에서 전체 개요 확인
2. `ARCHITECTURE.md`에서 구조와 데이터 흐름 확인
3. `TROUBLESHOOTING.md`에서 시행착오와 해결 근거 확인
4. `RETROSPECTIVE.md`에서 프로젝트 의미와 개선 방향 확인
5. `INTERVIEW.md`에서 발표/면접용 답변 확인

# FOMO Guard Web MVP

## 목적

이 페이지는 해커톤 심사용 MVP이다.

- 별도 API 키 없이 즉시 확인 가능
- 샘플 데이터 기본 제공
- CSV 업로드 지원
- 시간 흐름 기반 FOMO 진단 우선 노출
- 종목 추천 없이 멘토형 인사이트만 제공

## 파일 구성

- `index.html`: 메인 페이지
- `styles.css`: UI 스타일
- `app.js`: 분석 로직, CSV 파서, 렌더링 로직
- `sample_portfolio.csv`: 업로드 테스트용 샘플 데이터

## 로컬 실행

정적 파일이므로 별도 빌드 없이 브라우저에서 열 수 있다.

권장 방식:

1. `index.html` 파일을 브라우저에서 연다.
2. `샘플 데이터로 시작` 버튼을 누른다.
3. 또는 `sample_portfolio.csv` 파일을 업로드한다.

## 배포 권장 방식

정적 호스팅 서비스에 그대로 업로드하면 된다.

예시:

- Vercel
- Netlify
- GitHub Pages
- Cloudflare Pages

## 심사 관점 체크포인트

- 첫 화면에서 서비스 목적이 바로 드러나는지
- 샘플 데이터로 즉시 결과 확인이 가능한지
- 시간 정보 기반 정밀 진단과 추정 진단이 구분되는지
- FOMO 진단이 일반 수익률보다 먼저 보이는지
- 추천 문구 없이 점검 가이드 중심으로 구성되었는지
